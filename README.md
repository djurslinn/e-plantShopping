# e-plantShopping 🌱

## Project Name
e-plantShopping

## Project Overview
e-plantShopping is an online plant shopping web application that allows users to browse, select, and purchase plants through an interactive and user-friendly interface.

The application provides a modern shopping experience where users can explore different plant categories, add items to their cart, and manage their selections efficiently.

## Features
- Browse available plants
- View plant details
- Add plants to shopping cart
- Responsive user interface
- Fast development using Vite

## Technologies Used
- React.js
- Vite
- JavaScript
- HTML
- CSS
- Node.js & npm
